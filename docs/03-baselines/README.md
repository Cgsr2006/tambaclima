# Registro de baselines do Tambaclima

Este diretório identifica as três baselines previstas para a entrega. Em 25/11/2026, o repositório contém implementação de clima, painel de capitais, proxy Vercel, cache de sessão e fallback local. Isso não comprova que a implementação foi validada nem que a equipe aprovou uma baseline. Nenhuma tag Git está presente neste checkout.

| Identificador | Escopo | Situação verificada em 25/11/2026 | Critério para congelar |
|---|---|---|---|
| BL-REQ-S1 | ERS, requisitos, casos de uso, regras e RTM | Candidata à revisão | Resolver as lacunas da RTM e registrar aceite da equipe/CCB. |
| BL-IMPL-S2 | Código-fonte e configuração | Implementação presente no repositório; baseline não congelada | Revisar os ICs, registrar commit e tag aprovados. |
| BL-REL-S3 | Versão validada e publicada | Sem evidência de aceite ou tag neste checkout | Registrar resultados de validação e URL publicada, obter aceite responsável e fixar commit/tag. |

Quando uma baseline for aprovada, registrar neste diretório o commit SHA imutável, a tag, os ICs incluídos, a data e a autoridade que aprovou. O estado do Project pode ter mudado desde o último snapshot e deve ser consultado antes de atualizar o acompanhamento. Não registrar uma baseline como congelada apenas porque seu identificador foi criado.
