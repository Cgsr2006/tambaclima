# Registro de baselines do Tambaclima

Este diretório identifica as três baselines solicitadas para a entrega. Os identificadores e escopos estão definidos; nenhuma tag Git foi criada porque o quadro ainda mostra itens em andamento e a equipe ainda precisa revisar e aprovar os conteúdos.

| Identificador | Escopo | Situação em 10/11/2026 | Critério para congelar |
|---|---|---|---|
| BL-REQ-S1 | ERS, requisitos, casos de uso, regras e RTM | Candidata à revisão | Resolver as lacunas da RTM e registrar aceite da equipe/CCB. |
| BL-IMPL-S2 | Código-fonte e configuração | Ainda não estabelecida | Concluir e revisar as issues de implementação; registrar commit e tag aprovados. |
| BL-REL-S3 | Versão validada e publicada | Planejada | Validar a aplicação, registrar evidências e URL de release, e fixar commit/tag. |

Quando uma baseline for aprovada, registrar neste diretório o commit SHA imutável, a tag, os ICs incluídos, a data e a autoridade que aprovou. Não registrar uma baseline como congelada apenas porque seu identificador foi criado.
